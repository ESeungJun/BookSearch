# AI 단독 결정 — 작성자 리뷰용

AI 가 작성자 확인 없이 정한 것(`추천안 기본 채택`)을 모은다. 단계 리뷰 때 작성자와 함께 보고, 확정·변경되면 `decision-log.md` 1절에 반영하고 여기서 지운다. 번호는 매기지 않는다.
