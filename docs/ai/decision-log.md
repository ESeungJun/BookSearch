# 의사결정·AI 활용 기록

작성자(사람)가 내린 판단과, 그 판단 전후로 AI를 어디에 썼는지를 시간순으로 남긴다.
README 의 「AI 활용」 절(어떤 작업에 썼는지 / 어떻게 검증했는지 / 직접 판단해 바꾼 부분)은 이 문서에서만 옮겨 쓴다.

**기록 규칙**
- `판단` 칸에는 실제로 작성자가 한 판단만 적는다. AI 추천을 아무도 확인하지 않고 쓴 경우에는 `추천안 기본 채택`이라고 적고, 사용자 판단으로 세지 않는다.
- AI 추천과 다르게 정한 항목은 `AI 제안과 다름`으로 표시한다. README 의 「직접 판단해 바꾼 부분」은 이 표시가 있는 항목에서 옮긴다.
- 폐기한 안은 지우지 않고 「폐기한 안」으로 옮긴다. 폐기 이유도 함께 남긴다.
- ID 는 v1 에서 이어 쓴다. D-01~D-38 은 v1 기록이며 맨 아래 부록에 그대로 있다.
