- 실행 가능한 APK (debug 빌드 가능)
- README: 빌드 방법, 사용 프레임워크, 프로젝트 구조, 주요 구현 포인트 등
  - AI 활용 시: 어떤 작업에 AI를 활용했는지 / AI 결과를 어떻게 검증했는지 / AI 결과를 그대로 쓰지 않고 직접 판단해 바꾼 부분
  - 그 밖의 AI 사용 관련 문서(컨텍스트 파일, 작업 기록 등)는 자유 형식
- 시연 영상(선택): 3분 이내

## 빌드 조건
- Android Studio 최신 안정 버전에서 별도 설정 없이 빌드 (`./gradlew assembleDebug`)
- Gradle Wrapper 포함
- Gradle 9.4.1 / AGP 9.2.1 / Kotlin 2.4.0 (KSP 2.3.10) / JDK 17 / compileSdk 37
- 그 밖의 라이브러리 버전 자유
- API 키는 local.properties 에서 읽고, local.properties 를 제출물에 포함. 전형 종료까지 키 폐기 금지
- 제출: zip 으로 메일 회신(용량 초과 시 드라이브). 개인 GitHub 업로드 시 회사명 미포함

## 과제 목표
카카오 도서 검색 API를 활용한 도서 검색 앱

## 요구 사항
### (1) 기술 및 프레임워크
- Kotlin, Coroutine, Flow, Jetpack Compose
- 아키텍처·라이브러리 자유, AI 도구 자유

### (2) API
- Kakao Developers - 도서 검색 API (키는 빌드 조건 참고)

### (3) 화면 구성 및 주요 기능
**3-1. 하단 탭바 (2개)** — 탭1: 전체 리스트 / 탭2: 즐겨찾기 리스트

**3-2. 검색 리스트 화면 (탭1)**
- 리스트 아이템: 카드 형태. 도서정보(제목, 저자, 출판사, 출간일, 가격 등) 및 도서 이미지
- 검색: 질의어(Query) 기반 검색 (API)
- 정렬: 정확도순 / 발간일순 (API 쿼리 파라미터)
- 페이징: 1페이지 20개 단위 (API 페이징)
- 즐겨찾기 토글: 카드별 버튼, 즐겨찾기한 도서 정보는 로컬 저장
- 아이템 카드 탭 시 상세화면 이동

**3-3. 즐겨찾기 리스트 화면 (탭2)**
- 검색 리스트와 동일한 아이템 카드
- 검색: 질의어 기반 로컬 데이터 내 검색
- 로컬에 저장된 즐겨찾기 도서 정보 기반 UI
- 정렬/필터: 도서 제목 오름차순/내림차순, 금액 필터링
- 즐겨찾기 토글, 카드 탭 시 상세 이동

**3-4. 도서 상세 화면**
- 리스트에서 아이템 탭 시 진입
- 도서 이미지, 제목, 각종 정보 표시 (가이드: 저자·출판사·출간일·ISBN·정상가·할인가, 책 소개)
- 즐겨찾기 토글

### (4) 사용 환경 및 품질 조건
- 지하철처럼 네트워크가 불안정한 환경에서도 앱을 쓸 수 있어야 한다
- 태블릿·폴더블 사용자도 이 앱을 쓴다

### (5) 평가 안내
- 대규모 앱의 한 기능이며, 앞으로 다른 기능이 계속 추가되고 여러 개발자가 함께 작업한다고 가정
- 지금의 기능 규모가 아니라 위 전제에 맞는 구조
- 기능 개수보다 어떤 상황을 고려했는지, 그 판단 근거를 본다
- 모든 상황에 대응하지 않아도 됨. 고려했지만 구현하지 않은 것도 남길 것
- 이어받을 팀원이 무엇을 왜 그렇게 만들었는지 저장소 안에서 알 수 있게 (방법 자유)
